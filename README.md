# Decoding Hukum Website

A responsive, single-page website for Decoding Hukum.

## Files
- `index.html` — complete static website.

## Preview locally
Open `index.html` in a browser.

## Deploy with Vercel
1. In Vercel, choose **Add New → Project**.
2. Import `brardilpreet7171/decoding-hukum-website` from GitHub.
3. Use the default settings for a static HTML site and deploy.
4. In Vercel project **Settings → Domains**, add `decodinghukum.com` and `www.decodinghukum.com`.
5. In GoDaddy DNS management, enter the exact DNS records Vercel shows for this project. Do not delete existing MX/email records.

## Editing
Edit `index.html` in GitHub and commit to `main`. Once the repository is connected to Vercel, each commit can trigger a new deployment.

## Booking link
The “Book a session” call-to-action currently links to `https://www.decodinghukum.com`. Update the `href` in `index.html` to your actual scheduling or booking page when available.
